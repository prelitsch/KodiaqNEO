# Install this handoff into Codex's local workspace

This ZIP is a **handoff / research kit, NOT a car installer**. Don't copy this ZIP to the SD card.

## On Windows
1. Extract ALL files **from this ZIP** into your existing `C:\Users\aldin\OneDrive\Desktop\Kodiaq Moding` folder. Allow new folders/files; it does not replace M.I.B. firmware/backup files.
2. After extraction, `AGENTS.md`, `NEOUI_PROJECT_CONTEXT.md`, `NEOUI_TECHNICAL_STATE.md`, `NEOUI_DESIGN_AND_ROADMAP.md`, and `NEOUI_RESEARCH_TASKS.md` should be in the **root** of Kodiaq Moding, not inside another `NeoUI_Codex_Handoff` folder. (Windows Extract All sometimes nests directories.)
3. The ZIP additionally contains `reference_screens/` (eight photographed views) and `source_archives/` with Claude v2 artwork and read-only research files. Older original files already on your PC remain untouched.
4. Open Codex, select/open folder `Kodiaq Moding` as workspace, and paste the contents of `START_CODEX_HERE.txt` as your first task (or just ask it to read that file). If using a CLI, start Codex from the root directory.
5. Allow local file reads/controlled commands; review any permission to write outside the working subdirectories. Do **not** let a coding agent write directly to a plugged-in M.I.B. SD card or the head unit in the first phase.
